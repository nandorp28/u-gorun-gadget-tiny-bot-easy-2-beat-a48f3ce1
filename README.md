SteadyClip is a tiny deterministic paper-trading bot for hourly Solana prices, built for the make.fun Tiny Bot bounty (bars-replay/v1 harness). It buys the dip: enter when MACD(12, 26) is above its 9-bar signal line and CCI(14) is at or under −30, then exit the whole position on a MACD cross-down, a +4% take-profit, or a −5% stop. No AI model, no randomness, no clock: the same bars always produce the same orders. On the kit's dev window (Oct 29 – Nov 3, 2026, all seven symbols down 3–14%) it nets +$206.39 (+2.06%, 35 trades, 1.75% max drawdown) — against −$869.34 for buy-and-hold and −$20.22 for the kit's best baseline.

## Run it

```sh
node main.ts
```
